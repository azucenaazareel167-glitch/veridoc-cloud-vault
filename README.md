# VeriDoc: Next-Gen Digital Cloud Vault & Repository

VeriDoc is a secure, cloud-backed document verification and repository system designed to protect, store, and manage essential digital files with cryptographic security.

---

## 🌐 Live Demonstration
- **Live HTTPS Deployment:** https://veridoc-cloud-vault.vercel.app
- **SSL Security:** Automatic HTTPS encryption enabled via Vercel Edge Network

---

## 🛠 Tech Stack & Architecture

- **Frontend:** HTML5, Modern CSS3 (Responsive Design), Vanilla JavaScript (ES6+)
- **Backend & Database:** Supabase (PostgreSQL Cloud Instance)
- **File Storage:** Supabase Buckets (10MB Cap)
- **Security & Integrity:** SHA-256 Digital Hashing, RPC Administrative PIN Verification

---

## 🔑 Key Features

1. **Secure Document Backup:** Encrypts and stores important user files safely in the cloud.
2. **Instant File Retrieval:** Allows quick searching and fetching of documents using generated hashes.
3. **SHA-256 Hashing:** Guarantees file integrity and tamper-proof storage.
4. **RPC PIN Administrative Deletion:** Ensures secure, authorized deletion of stored records using database procedure calls.
